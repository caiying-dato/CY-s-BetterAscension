# A11~A20 实测清单

> 代码已全部写完并部署。**所有条目都需要你在游戏里实跑**——我这边跑不了游戏。
> 每条都给了「怎么触发」和「日志里该看到什么」，日志一律在
> `%APPDATA%\SlayTheSpire2\logs\godot.log`，过滤 `[BetterAscension]` 即可。

---

## 0. 期望的启动日志（先确认这个）

```
[BetterAscension] CY's BetterAscension v0.1.0 正在初始化……
[BetterAscension] 发现 16 个补丁类：ActAttritionPatch、AscendersBaneEtherealPatch、...
[BetterAscension] 已安装补丁 ...ActAttritionPatch（1 个方法）。
...（16 个类各一条）
[BetterAscension] 补丁安装结束，共 16 个补丁类、16 个方法。
[BetterAscension] 已注册进阶 11 → ... 20 → ...
[BetterAscension] 自定义进阶枚举就绪，本模组开始生效。
```

**关键判据**：`发现 16 个` / `共 16 个补丁类、16 个方法` —— 两个数字必须相等且为 16。
不相等就说明又有补丁静默没装上（见 `docs\实测记录-Harmony补丁静默缺失.md`）。

且**不应**出现任何 `[ERROR] [BetterAscension]` 行。

## 2. 逐条验证

> **提示**：进阶是"高阶包含低阶"，所以**以 A20 开局能一次性验证全部 10 条**。
> 想单条验证就以对应等级开局。

### A11 · 精英强敌（精英 +1 力量）

**触发**：以 A11+ 开局，进一个精英房。

**期望日志**：
```
A11 精英强化：<精英名> 获得 1 点力量（现在 1）。
```
**画面**：精英身上出现力量图标，伤害预览把 +1 算进去。
**反例**：进**普通**战斗时敌人**不该**有力量。普通战斗会打这种限量诊断行：
```
A11 精英判定：'<怪名>' 跳过（不是精英房；mapPoint=Monster, room=Monster, isEnemy=True）。
```

---

### A12 · 水土不服（换幕 -6 最大生命）

**触发**：以 A12+ 开局，打完第 1 幕的 Boss、进入第 2 幕。再进第 3 幕。

**期望日志**（共 2 次）：
```
A12 水土不服：进入第 2 幕，最大生命 <N> → <N-6>（当前生命 <M>）。
A12 水土不服：进入第 3 幕，最大生命 <N-6> → <N-12>（当前生命 <M-6>）。
```
**画面**：血条上限减少。
⚠️ 当前生命会**跟着降**（`SetMaxHpInternal` 会把 `CurrentHp` 夹到新上限以下）。如果你期望"只减上限、当前生命不变"，告诉我，改一行即可。

---

### A13 · ？富有？（买卡扣 15 金币小费）

**触发**：以 A13+ 开局，在商店买一张卡。

**期望日志**：
```
A13 富有：购买卡牌扣小费 15 枚金币（<A> → <A-15>，应收 15）。
```
**关键边界**：金币不足 15 时，`actual` 会小于 15，且**金币停在 0 不会变负**：
```
A13 富有：购买卡牌扣小费 7 枚金币（7 → 0，应收 15）。
```
**反例**：买**遗物**或**药水**时**不该**有小费日志。

### A14 · 咬紧牙关（手牌上限 10 → 9）

**触发**：以 A14+ 开局，进任意战斗，手里屯牌直到抽满。

**期望日志**（每场战斗的第一次抽牌时打一次，可能刷屏，故没限量但只在变化时打）：
```
A14 咬紧牙关：手牌上限 10 → 9。
```
**画面**：手里最多 9 张，第 10 张抽不进来（会有"手牌已满"的提示气泡）。

### A15 · 进阶之灾+（失去虚无）

**触发**：以 A15+ 开局（A5 会自动给你「进阶之灾」这张诅咒）。查看牌组里那张牌。

**期望日志**：
```
A15 进阶之灾+：已移除 [虚无]，剩余关键字 [Eternal, Unplayable]。
```
**画面**：牌面**没有**「虚无」这个词条。
**关键行为**：回合结束时，这张牌**不会**因为虚无被消耗掉，会留在手里。

---

### A16 · 通货膨胀+（商店卡价 +20%）

**触发**：以 A16+ 开局，进商店看卡牌价格。

**期望日志**（限量 8 条）：
```
A16 通货膨胀+：卡牌价格 <原价> → <新价>。
```
**期望数值**（基础价实测为 Common 50 / Uncommon 75 / Rare 150，无色牌 ×1.15，再乘 0.95~1.05 随机）：
- 普通卡 ≈ 57~63（原 47~53）
- 稀有卡 ≈ 171~189（原 142~158）

**反例**：遗物、药水价格**不该**有这条日志。
**注意**：打折卡会显示 `新价 = 原标价×1.2`，与"先打折再涨价"还是"先涨价再打折"有关 —— 如果你对打折卡的期望值有具体要求，告诉我。

---

### A17 · 珍稀（药水掉率 40% → 30%）

**触发**：以 A17+ 开局。**必须是新开局**（读档续玩会沿用存档里的历史值）。

**期望日志**（限量 4 条）：
```
A17 珍稀：药水掉落起点概率 40% → 30%。
```
**实际感受**：药水明显变少。注意游戏本身有 ±10% 的自适应漂移（掉落后概率降、不掉则升），
**这个机制我们没动**，只把起点压低了。

---

### A18 / A19 · 柔弱身躯 / 无力攻击（开局 1 层脆弱 / 虚弱）

**触发**：以 A18+ 开局，进任意战斗（普通/精英/Boss 都该生效）。

**期望日志**：
```
A18 柔弱身躯：<NetId> 获得 1 层脆弱（现在 1）。
A19 无力攻击：<NetId> 获得 1 层虚弱（现在 1）。
```
**画面**：玩家身上出现脆弱（蓝）与虚弱图标，且第一回合就已经在。
⚠️ **重点看时机**：能力是否在你**出第一张牌之前**就挂上了？如果晚了（比如第一张牌没吃到虚弱），告诉我，需要换挂载点。

**反例**：以 A17 开局时**不该**有这两条日志。

---

### A20 · 最终考验（进 Boss 战加一张诅咒）

**触发**：以 A20 开局，打到 Boss 房进场。

**期望日志**：
```
A20 最终考验：进入 Boss 战，随机诅咒 [<卡名>] 已加入卡组（牌组 <N> → <N+1> 张）。
```
**画面**：打开牌组能看到多了一张诅咒，且**打完这场 Boss 后它还在**（是永久加入，不是本场临时）。
**反例**：进普通战斗、精英战**不该**加诅咒。

## 3. 出错时怎么调

| 日志 | 含义 & 改法 |
| --- | --- |
| `A11 精英判定：... 跳过（不是精英房）` | 正常诊断。若**精英房里**也出现这行，说明房间判定看错了值 |
| `在 'Xxx' 里没找到任何上限字面量 10` | 游戏改写了那个方法。跑 `check.cmd` 对照新版 IL |
| `BaseLib 尚未为 [CustomEnum] 字段生成值` | BaseLib 没装好或没启用 |
| `读不到店主玩家（MerchantEntry._player）` | A13 的反射取值失败，游戏改了字段名 |
| `找不到 RunState.CreateCard(Player)` | A20 的 API 改名 |
| 界面显示 `LEVEL_11.title` | 本地化路径问题，查 `Found loc table from mod: zhs ascension.json` |
| 游戏卡死/无响应 | **几乎一定是主线程同步等待异步**。本项目所有能力施加都走同步内核，若仍卡死请把日志最后几行给我 |

## 4. 已知限制（不是 bug，是我的实现选择）

1. **A12 / A20 的幂等保护是内存态**：换幕途中存档→退出→读档后再触发换幕，理论上可能重复扣血/重复加诅咒。
   若要彻底解决需要把标记写进存档，得另想办法（`RunState.ExtraFields` 实测只有三个固定字段，不是通用字典）。
2. **A17 只在**新开局**生效**：`CurrentValue` 会被存档，读档续玩沿用存档值。这是刻意的。
3. **A13 用反射读 `MerchantEntry._player`**：Publicizer 没公开这个 protected 字段。
4. **多人游戏未实测**：上限与各效果都按"对所有玩家生效"写，但没有多人同局验证。
